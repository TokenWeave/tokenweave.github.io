Install on macOS or Linux

These instructions apply when the V4 FP32 model download is available. You must already have an authorized copy of the TokenWeave runtime; the API does not distribute the runtime or source code. Python 3.11 or 3.12 and Git are required for the runtime. Inference runs on your machine.

1. Verify and extract

Save the model ZIP and checksum in the same directory. From your existing TokenWeave runtime directory, extract into a fresh checkpoint folder. These examples assume the files are in ~/Downloads.

(cd ~/Downloads && shasum -a 256 -c tokenweave-v4-model.zip.sha256)
# Stop if verification fails; run from the runtime directory.
mkdir -p checkpoints/v4
mkdir checkpoints/v4/context-pilot && unzip ~/Downloads/tokenweave-v4-model.zip -d checkpoints/v4/context-pilot

On Linux, use sha256sum -c tokenweave-v4-model.zip.sha256. Stop if the checksum fails.

2. Install runtime and check the model
sh setup_local.sh fp32
export TW_MODEL="$PWD/checkpoints/v4/context-pilot"
.venv/bin/python verify_checkpoint.py "$TW_MODEL"

If needed, set PYTHON=python3.12 before running the setup script. Read the included README for details.

3. Run a local smoke test
git clone https://github.com/relaton/relaton-bib.git "$HOME/tokenweave-demo"
export TW_REPO="$HOME/tokenweave-demo"
.venv/bin/python smoke_mcp.py "$TW_REPO" --model-output "$TW_MODEL"

Start on a public test repository. Model-selected excerpts are advisory and may be incomplete.

4. Connect your coding agent

Claude Code: merge the generated JSON into the project's .mcp.json. Codex: merge the generated TOML into ~/.codex/config.toml. Do not overwrite your other MCP settings.

.venv/bin/python configure.py "$TW_REPO" --client claude --model-output "$TW_MODEL" --experimental
.venv/bin/python configure.py "$TW_REPO" --client codex --model-output "$TW_MODEL" --experimental

Run only the command for your client. Restart it and inspect the MCP tools. Exact lookups should bypass the model; verify advisory results and fall back to native tools when needed.

Troubleshooting

Download is slow or the server is offline

Click Download model once. If Render is waking up, the button is disabled and checks continue automatically for up to three minutes. The countdown is estimated. If the gateway responds but is not ready to serve the model, try again later. If it remains unreachable, use Check again after a few minutes. The static site and these instructions remain accessible independently of Render.

Do I need a GitHub account?

No GitHub account is needed to download the model. Authorized users receive a separate download key. The runtime must be obtained independently from an authorized copy.

Will Render downtime stop TokenWeave?

No. After installation and dependency setup, the model runs locally. Render is only used to obtain the model archive.

Is this a production model?

No. This is an experimental read-only preview for eligible Ruby source. Accuracy on real tasks, M1 performance, token savings and concurrency still need validation.
