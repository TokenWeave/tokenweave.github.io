Get started

1. Authenticate GitHub

Sign in with an account that has access to the private source and model repositories.

2. Clone the project
git clone https://github.com/TokenWeave/tokenweave.git
cd tokenweave
./setup_local.sh fp32

Python 3.11 or 3.12 and Git are required.

3. Install a development checkpoint

Follow the private README for the current checkpoint and local smoke tests. Do not use a checkpoint for production or assume relevance is guaranteed.
